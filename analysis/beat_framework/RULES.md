# Beat 固定分析框架（每次强制）

## 一句话用法

用户发送：`xxxusdt现价做多还是做空`  
→ 必须按本文件 8 步 + 统一输出格式作答，禁止跳步。

## 硬规则（总纲）

1. **OI 只做筛选，不做方向结论，更不是最终开仓许可**。
2. **必须过闸门 F（资金费率）**：极端拥挤方向不可追。
3. **RANGE 不能当单边**：价格处于震荡时，即使 OI 强/极强也输出观望。
4. **数据以当时能拉到的交易所为准**（Gate / Binance / OKX / MEXC / Bybit…），拉不到标 `N/A`。
5. **main 分支不承载行情数据**；实时数据来自交易所 API。

## 一、推荐合约强制闸门（开多/开空前）

### 1.1 默认观望（禁止现价多）

出现任一则 **禁止给出现价做多**，结论默认 **观望**：

- 短线 **空增仓**（5m/15m 为 Q2，或短线 OI↑ 且价格↓）
- **EMA 空头**（15m 或 1h：价在 EMA20 下 + EMA20&lt;EMA50 / 空头排列）

### 1.2 开多许可（必须同时满足）

1. **结构 UP**（单边偏多）**或** 明确 **突破确认**（收盘突破近端 swing high）  
2. **OI 仍多增仓**（Q1，且 15m/1h OI 变化 ≥ 0，禁止短线已减仓还追多）  
3. 过闸门 F；非 RANGE；无短线 OI 背离一票否决

### 1.3 开空许可（对称）

1. 结构 DOWN 或跌破确认  
2. OI 仍空增仓（Q2，短线 OI 未明显回落）  
3. 过闸门 F；非 RANGE；无短线 OI 背离

### 1.4 「OI强 / 极强」定位

- 只是 **筛选条件之一**，**不是**最终开仓许可。  
- 若 OI 明确 **极强**，依据里必须提示：`OI提示：极强（仅雷达，未过闸门不得开仓）`。  
- 未过结构/背离/F/位置闸门时，结论写：**极强但观望**（归入观望类，可在结论旁标注）。

## 二、OI 强度标注（每次依据必带）

### 2.1 分级（仅针对增仓象限 Q1/Q2）

| 级别 | 条件（满足任一窗口，且为增仓象限） |
|------|-------------------------------------|
| 普通 | 各窗 \|ΔOI\| 均 &lt; 3% |
| 强 | 15m/1h/4h 任一 \|ΔOI\| ≥ 3% 且 &lt; 10% |
| 极强 | 15m/1h/4h 任一 \|ΔOI\| ≥ 10%，**或** 5m \|ΔOI\| ≥ 5% 且同向增仓 |

### 2.2 禁止标极强 / 禁止用减仓窗抬强度

- **平仓 / 去杠杆**（Q3/Q4，OI↓）即使变动再大，**禁止**标「极强」「强」。  
- 最多写：`OI强度：普通 ＋ 跌价减仓/涨价减仓 ＋ 5m/15m/1h/4h`。  
- **短线减仓窗占优**（5m/15m/1h 多数为减仓，或 1h OI&lt;0）→ 一律按减仓/去杠杆标 **普通**，即便单窗 15m 微幅增仓。  
- 强度数字 **只统计增仓象限窗口**；减仓窗的大 \|ΔOI\| 不得抬到「强/极强」。

### 2.3 依据固定句式（强制）

```
OI强度：普通|强|极强 ＋ 方向(多增仓/空增仓/减仓) ＋ 5m=.. 15m=.. 1h=.. 4h=..
```

示例：`OI强度：极强 ＋ 空增仓 ＋ 5m=+2.1 15m=+6.4 1h=+12.0 4h=+41.6`  
未过闸：`结论：极强但观望` + 同上依据。

## 三、庄币 / TUT 类：三维雷达 → 观察池（禁止自动跟单）

详见 `analysis/newsliquid/`。事件只进 **观察池**，开仓仍走结构+位置+闸门 F。

| 事件 | 含义 | MVP |
|------|------|-----|
| `OI_SPIKE` | 短窗 OI 增速过阈 + 增仓象限 | ✅ 立刻可扫 |
| `OI_CONCENTRATION` | top 持仓/总 OI ≥ 50%（或分位）且与价格同向 | ✅ Gate `top_*_size` |
| `WHALE_PNL_START` | 主力同向仓位价值/浮盈由负转正 | ❌ 无付费源前禁止假装 |

执行层否决（cion / 闸门 F）：

- 结构确认（禁止 RANGE 当单边）
- 短线 OI 背离一票否决
- **tipH / tipL 不追**（庄币启动后最易变对手盘）
- 费率拥挤、或 24h 已翻倍 → 事件降级为「观察/止盈」，禁止追开

一句话：**三维适合做启动雷达；进场仍要结构+位置，否则专抓庄币=专给庄接盘。**

## 固定 8 步

1. 现价：多所现价、24h 高低、相对位置  
2. OI：5m/15m/1h/4h + 四象限 + **强度分级**  
3. 结构：高低点、突破/跌破、单边 vs 震荡  
4. 周期：5m/15m/1h/4h 的 RSI、均线、阴阳线  
5. 资金费率：拥挤与多空成本（闸门 F）  
6. 事件：newsliquid 观察池 / 新闻 / 链上（无则 N/A）  
7. 结论：做多 / 做空 / 观望 / **极强但观望**  
8. 执行：入场、止损、止盈、失效条件  

## OI 四象限

| 价格 | OI | 象限 | 含义 |
|------|-----|------|------|
| ↑ | ↑ | Q1 | 多增仓 |
| ↓ | ↑ | Q2 | 空增仓 |
| ↑ | ↓ | Q3 | 涨价减仓（去杠杆） |
| ↓ | ↓ | Q4 | 跌价减仓（去杠杆） |

单边候选 **仅 Q1/Q2**。

## 闸门 F

- 多头拥挤：费率 &gt; **0.05%/周期** → F 失败  
- 空头拥挤：费率 &lt; **-0.05%/周期** → F 失败  

## 统一输出格式（每次）

```
•结论：做多/做空/观望/极强但观望
•依据：价格；OI强度：x＋方向＋5m/15m/1h/4h；结构；周期；费率
•执行单：入场 / 止损 / 止盈
•失效条件：...
```

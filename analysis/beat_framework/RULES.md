# Beat 固定分析框架（每次强制）

## 一句话用法

用户发送：`xxxusdt现价做多还是做空`  
→ 必须按本文件 8 步 + 统一输出格式作答，禁止跳步。

## 硬规则

1. **OI 只做筛选，不做方向结论**。
2. **必须过闸门 F（资金费率）**：极端拥挤方向不可追。
3. **RANGE 不能当单边**：价格处于震荡时，即使 OI 强也输出观望/区间策略，不得给单边趋势单。
4. **数据以当时能拉到的交易所为准**（Gate / Binance / OKX / MEXC / Bybit…），拉不到的源在报告中标注 `N/A`。
5. **main 分支不承载行情数据**；实时数据来自交易所 API。本目录脚本是固化规则与可复现跑数入口。

## 固定 8 步

1. **现价**：多所现价、24h 高/低、相对位置（距高/距低/区间百分位）
2. **OI**：5m / 15m / 1h / 4h 变化 + 价格涨跌 → 四象限
3. **结构**：高低点、是否突破/跌破、单边 vs 震荡
4. **周期**：5m / 15m / 1h / 4h 的 RSI、均线、阴阳线
5. **资金费率**：是否拥挤、多空成本（闸门 F）
6. **事件**：新闻/舆情/大额转账/宏观环境（拉不到则写明）
7. **结论**：明确 做多 / 做空 / 观望
8. **执行**：入场、止损、止盈、失效条件

## OI 四象限（价格 × OI）

| 价格 | OI | 象限 | 含义 |
|------|-----|------|------|
| ↑ | ↑ | Q1 | 涨价增仓（多头单边候选） |
| ↓ | ↑ | Q2 | 跌价增仓（空头单边候选） |
| ↑ | ↓ | Q3 | 涨价减仓（回补/减仓，非强单边） |
| ↓ | ↓ | Q4 | 跌价减仓（清算/离场，非强单边） |

单边候选 **仅 Q1 / Q2**；Q3/Q4 与 RANGE 一律不得标成“OI强单边”。

## 闸门 F（费率）

- 做多候选：资金费率过高（多头过度拥挤）→ **F 失败**，降级观望。
- 做空候选：资金费率过低/大幅为负（空头过度拥挤）→ **F 失败**，降级观望。
- 默认阈值（可随品种波动调整，但必须写明）：  
  - 多头拥挤：费率 > **0.05%/周期**  
  - 空头拥挤：费率 < **-0.05%/周期**

## RANGE 判定（满足任一）

- 24h 绝对涨跌幅 < 2%，或  
- |涨跌幅| / 24h振幅 < 0.30，或  
- 多周期结构互相矛盾且无明确突破/跌破

## 统一输出格式（每次）

```
•结论：做多/做空/观望
•依据：价格、OI、结构、5m/15m/1h/4h、费率
•执行单：入场 / 止损 / 止盈
•失效条件：...
```

## 固化报告模板板块

1. 交易行情（多所现价/结构/周期）
2. 链上交易（可得则写，否则 N/A）
3. 舆情（新闻、社交）
4. 大额转账（可得则写，否则 N/A）
5. 衍生品 OI / 资金费（Bybit 优先；不可用则 Gate/OKX/MEXC）
6. CryptoPanic 专业新闻（不可用则替代新闻源）
7. 市场环境（BTC/ETH 状态、Fear&Greed 等）

## 运行

```bash
python3 analysis/beat_framework/analyze.py BEATUSDT
python3 analysis/beat_framework/analyze.py BTCUSDT --scan
```

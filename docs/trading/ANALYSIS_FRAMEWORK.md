# 合约多空分析强制框架

触发语：`xxxusdt现价做多还是做空` → 必须按本框架输出，禁止跳步。

## 一、固定分析步骤（每次）

1. **现价**：多所现价、24h 高低、相对位置（日内/近端摆动）
2. **OI**：5m/15m/1h/4h 变化，结合涨跌做四象限  
   - 价涨+OI涨 = 多增仓  
   - 价涨+OI跌 = 空平仓  
   - 价跌+OI涨 = 空增仓  
   - 价跌+OI跌 = 多平仓  
3. **结构**：高低点、是否突破/跌破、单边 vs 震荡（RANGE 禁止当单边）
4. **周期**：5m/15m/1h/4h 的 RSI、均线、阴阳线
5. **资金费率**：拥挤度、多空成本
6. **事件**：解锁、上币、清算潮、舆情等
7. **结论**：明确 做多 / 做空 / 观望
8. **执行**：入场、止损、止盈、失效条件

## 二、固化报告模板（章节顺序）

1. 交易行情  
2. 链上交易（有源才写，无源标明「无源」）  
3. 舆情（新闻、社交）  
4. 大额转账（有源才写）  
5. Bybit/Gate 等衍生品 OI / 资金费  
6. CryptoPanic / 专业新闻  
7. 市场环境（BTC 等）  
8. 结论 + 执行单  

数据以当时能拉到的交易所为准（Gate / Binance / OKX / MEXC / Bybit 等）；拉不到写明失败，不编造。

## 三、推荐合约闸门

1. 有**短线空增仓** 或 **EMA 空头排列** → 默认 **观望**，不给现价多  
2. 必须 **结构 UP** 或 **突破确认** + **OI 仍多增仓** 才开多  
3. 「OI 强」只是筛选条件之一，不是最终开仓许可；OI 明确极强时给出提示  

## 四、OI 强度标注

格式：`OI强度：普通/强/极强 ＋ 方向 ＋ 5m/15m/1h/4h 数字`

规则：

1. **平仓/去杠杆**即使变动大，也**禁止**标极强 → 标普通（可附注变动幅度）  
2. 极强仍要过结构/背离闸门；未过写 **「极强但观望」**  
3. 短线 OI 背离 → 一票否决开仓  

建议阈值（可调）：

| 档位 | |\Delta OI|（对照窗口） |
|------|------------------|
| 普通 | < 3% |
| 强   | 3% – 8% |
| 极强 | ≥ 8% 且非平仓象限 |

## 五、庄币（TUT 类）三维雷达 → 执行闸门

事件只进**观察池**，开仓仍过结构闸门：

1. `OI_SPIKE`：短窗 OI 增速过阈 + 增仓象限  
2. `OI_CONCENTRATION`：top 持仓/总 OI 升破 50%（或分位）且与价格同向  
3. `WHALE_PNL_START`（有源才启用）：主力同向仓位价值/浮盈由负转正或斜率转正  

执行层禁止：

- RANGE 当单边  
- 短线 OI 背离开仓  
- tipH / tipL 追单  
- 费率拥挤、24h 已翻倍 → 降级为观察/止盈，不追开  

落地顺序见 `schemas/newsliquid/event-schema.json`。

## 六、统一输出格式

```
•结论：做多/做空/观望
•依据：价格、OI、结构、5m/15m/1h/4h、费率
•执行单：入场 / 止损 / 止盈
•失效条件
•OI强度：普通|强|极强 ＋ 方向 ＋ 5m/15m/1h/4h 数字
```

# 合约多空分析强制框架

触发语：`xxxusdt现价做多还是做空` → 必须按本框架输出，禁止跳步。

数据以当时能拉到的交易所为准（Gate / Binance / OKX / MEXC / Bybit 等）；`main` 分支不承载行情，实时数据来自 API。事件 JSON 契约见 `src/newsliquid/schemas/event.schema.json`。

## 一、固定分析步骤（每次强制）

1. **现价**：多所现价、24h 高低、相对位置
2. **OI**：5m/15m/1h/4h 变化，结合涨跌做四象限 + **强度分级**
3. **结构**：高低点、是否突破/跌破、单边 vs 震荡（RANGE 禁止当单边）
4. **周期**：5m/15m/1h/4h 的 RSI、均线、阴阳线
5. **资金费率**：拥挤度、多空成本（闸门 F）
6. **事件**：newsliquid 观察池 / 解锁 / 舆情 / 链上（无源标 N/A）
7. **结论**：做多 / 做空 / 观望 / **极强但观望**
8. **执行**：入场、止损、止盈、失效条件

## 二、固化报告模板（章节顺序）

1. 交易行情（多所现价、OI 四象限、结构、多周期）
2. 链上交易（有源才写，无源标明）
3. 舆情（新闻、社交）
4. 大额转账（有源才写）
5. Bybit / Gate 等衍生品 OI / 资金费
6. CryptoPanic / 专业新闻
7. 市场环境（BTC、ETH、Fear&Greed）
8. **统一结论区**（结论 / 依据 / 执行单 / 失效条件）

## 三、推荐合约闸门

1. 有**短线空增仓** 或 **EMA 空头排列** → 默认 **观望**，不给现价多
2. 必须 **结构 UP** 或 **突破确认** + **OI 仍多增仓** 才开多
3. 「OI 强」只是筛选条件之一，不是最终开仓许可；OI 明确极强时给出提示

## 四、OI 强度标注

格式（依据必带）：

```
OI强度：普通|强|极强 ＋ 方向(多增仓/空增仓/减仓) ＋ 5m=.. 15m=.. 1h=.. 4h=..
```

规则：

1. **平仓/去杠杆**（Q3/Q4）即使变动大，也**禁止**标极强
2. 极强仍要过结构/背离闸门；未过写 **「极强但观望」**
3. 短线 OI 背离 → 一票否决开仓

| 档位 | 条件（增仓象限 Q1/Q2） |
|------|------------------------|
| 普通 | 各窗 \|ΔOI\| 均 < 3% |
| 强 | 15m/1h/4h 任一 ≥ 3% 且 < 10% |
| 极强 | 15m/1h/4h 任一 ≥ 10%，或 5m ≥ 5% 且同向增仓 |

## 五、庄币（TUT 类）三维雷达 → 观察池

事件只进**观察池**，开仓仍过结构闸门 + 闸门 F：

| 事件 | 含义 | 状态 |
|------|------|------|
| `OI_SPIKE` | 短窗 OI 增速过阈 + 增仓象限 | ✅ MVP |
| `OI_CONCENTRATION` | top 持仓/总 OI ≥ 50% 且与价格同向 | ✅ Gate 代理 |
| `WHALE_PNL_START` | 主力同向浮盈由负转正 | ❌ 无付费源前 blocked |

执行层否决：

- RANGE 当单边
- 短线 OI 背离开仓
- tipH / tipL 不追
- 费率拥挤、24h 已翻倍 → 降级观察/止盈，不追开

一句话：**三维适合做启动雷达；进场仍要结构+位置，否则专抓庄币=专给庄接盘。**

## 六、统一输出格式（每次）

```
•结论：做多/做空/观望/极强但观望
•依据：价格；OI强度+方向+5m/15m/1h/4h；结构；周期；费率
•执行单：入场 / 止损 / 止盈
•失效条件：...
```

## 七、运行

```bash
# 单币完整分析（推荐入口）
python3 scripts/analyze_contract.py BTCUSDT

# 或直接调用框架
python3 analysis/beat_framework/analyze.py BTCUSDT

# 庄币/OI 异动雷达（观察池）
python3 analysis/newsliquid/scan_events.py --startup
```

详细硬规则见 `analysis/beat_framework/RULES.md`；报告填空模板见 `analysis/beat_framework/REPORT_TEMPLATE.md`。
